# Pure Combo Caller

A separate Android app dedicated entirely to calling the supplied 898 combination slots.

- No camera
- No video analysis
- No pose detection
- No network
- No runtime permissions
- Random, shuffle-deck, and sequential modes
- 1, 2, 3, 5, 10, or 20 repeats per combination
- Adjustable call interval, voice speed, and round duration
- Full-screen training mode
